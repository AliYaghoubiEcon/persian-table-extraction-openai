# Persian Table Extraction with OpenAI

This project explores the use of large language models (OpenAI)
to extract, clean, and structure Persian tables from semi-structured sources
such as PDFs and scanned documents.

## Motivation
Persian statistical tables often suffer from:
- Broken layouts
- Encoding issues
- Inconsistent column alignment

This project demonstrates how LLMs can assist traditional tools
to recover structured tabular data.

## Tools
- Python
- OpenAI API
- pandas


## Status
